- `Kit · A2 컴포넌트와 기초`: 색 · 잉크 불투명도 · 글자 · 모서리 · 그림자, 컴포넌트

## A2 규칙

| 항목 | A (지금) | A2 |
|---|---|---|
| 색 | A 토큰 | 그대로. 새 색 없음 |
| 선 | 검은 1px 구획선 `#1C1F23` | 잉크 6–12% 머리카락선(`--a6` `--a8` `--a12`) |
| 틀 | 세 영역이 선으로 붙음 | 사이드바는 캔버스 위, 대화와 오른쪽 열은 떠 있는 패널(r14, `--sh-sm`), 바깥 여백 8 |
| 모서리 | 2px | 태그·배지 6, 버튼·칩 8, 입력·안내 10, 카드 12, 패널 14, 대화상자 16 |
| 면 | surface와 raised | 카드 면은 흰색(`--white`), 옅은 바탕은 잉크 4–6% |
| 검은 칠 | 태그, 활성 탭, 단계 숫자 | 주 버튼과 Pablo 아바타에만 |
| 단계 | 원 숫자 + 선 | 위쪽 3px 진행 막대(완료 잉크 · 지금 주황 · 남음 잉크 10%) |
| 탭 · 보기 | 검은 칠 | 잉크 5% 틀 안의 흰 칸 + 그림자 |
| 링크 | 밑줄 | 굵기(600). 올리면 밑줄 |
| 점선 | 제안 · 오래됨 · 확인 필요 | 옅은 바탕. 확인 필요 카드는 흰 카드 + 왼쪽 주황 3px |
| 아이콘 | 글자(☰ ✎ ↑) | 선 아이콘 `ico(name, size)`(Kit a2/icon과 같은 모양) |
| 주황 | 사람의 판단이 필요한 곳 | 같음: 지금 단계, 확인 필요, 막음, 다름, 제안, 인용, 사람 태그 |

## 나누어 하기

0 단계(리드)가 깐 것: `:root`의 A2 토큰, 떠 있는 패널 틀, 링크·`code`·`.pill`의 공통 모양, `ico()`와 `ICONS`.
`viewer.py`의 CSS 끝에 영역 표시 주석이 있고, 영역마다 자기 표시 사이에만 규칙을 씁니다.

| B · 대화 · 카드 · 입력창 | `/* A2 · conversation … */` | `msg`, `tagRow`, `tagEdit`, `byStage`, `byTarget`, `conversation()`, 입력창 · 모델 메뉴 · `#acct` · `#adder` |
| C · 오른쪽 열 · 패널 · 대화상자 · 빈 화면 | `/* A2 · right column … */` | `ptabs()`, `intent()`, `plan()`, `trace()`, 패널 머리, 새 작업 양식, 설정 대화상자, `empty()` |

## 지킬 계약

`docs/plan-ui-renewal.md`의 '지킨 계약'을 모두 지킵니다. 덧붙여:
- id · class · `data-*` 이름을 바꾸거나 지우지 않습니다. 새 요소는 더해도 됩니다.
- 테스트가 `textContent`로 찾는 문구(예: `현재 원문 열기`, `알겠습니다`, `플랜 사용 가능`, 단계 이름, 링크 문구)를 바꾸지 않습니다. 아이콘은 글자가 없는 SVG(`aria-hidden`)라 `textContent`에 섞이지 않습니다.
- `#chat > .composer`의 첫 button은 송신/중지입니다.
- `viewer.py`는 CRLF입니다.
