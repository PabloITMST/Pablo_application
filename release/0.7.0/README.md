# Pablo 0.7.0

Pablo는 ChatGPT 계정으로 Codex 에이전트를 쓰는 Windows 데스크톱 앱입니다.
작업 기준을 지키는지 Guard가 확인합니다.
논문을 재현하는 작업이면 논문의 조건을 원문 쪽에 고정하고, 코드가 그 조건에서 벗어났는지 점검합니다.

## 0.6.0 이후 바뀐 것

### 논문 재현

- **📋 재현 조건 뽑기**: 작업에 붙인 논문 PDF에서 데이터셋, 데이터 분할, 모델, 하이퍼파라미터, 평가 지표, 비교 대상, 보고된 결과, 평가 규칙을 뽑습니다. 조건마다 원문 문장을 그 쪽에 고정합니다. 원문에서 위치를 찾지 못한 조건은 버립니다. 논문에 없는 설정(시드, 반복 횟수 등)은 따로 보여 줍니다. LinearRAG에서 조건 25개를 고정했고, 버린 것은 0개였습니다(43초).
- 에이전트는 이 조건들을 알고 일합니다. 논문에 적힌 값을 근거 없이 바꾸려 하면 Guard가 막고, 근거 쪽을 함께 보여 줍니다.
- **🔎 재현 점검**: 에이전트가 작업 폴더의 코드, 설정, 실행 로그를 읽고 조건마다 따름, 다름, 아직 없음, 코드가 정함을 판정합니다. 판정에는 파일 줄과 그 자리의 값이 붙습니다. 보고된 결과는 로그의 값과 대조합니다. 읽기 전용이라 파일은 바뀌지 않습니다.
- **보낼 곳**: 논문 PDF와 작업 폴더가 둘 다 있는 작업은 메시지마다 어디로 보낼지 묻지 않습니다. 기본은 에이전트이고, 도구 막대의 "💬 보낼 곳"에서 "논문 질문"으로 바꾸면 그 작업에서는 계속 그쪽으로 보냅니다.
- **논문 재현 작업**: 새 작업을 만들 때 고르면 세 기준이 함께 들어갑니다. 평가 데이터로 튜닝하지 않기, 논문 설정을 근거 없이 바꾸지 않기, 결과 수치를 직접 써 넣지 않기입니다.

### 코딩

- **🌐 인터넷**: 작업마다 허용하거나 차단합니다. 기본은 차단입니다. 패키지 설치, 데이터 내려받기, `git clone`에 필요합니다. 허용해도 명령은 하나하나 Guard를 거칩니다.
- **중지**: 에이전트가 일하는 동안 보내기 버튼이 ■가 됩니다.
- **변경 카드와 되돌리기**: 요청 하나로 작업 폴더의 파일이 바뀌면 "파일 N개가 바뀌었습니다" 카드가 붙습니다. 카드에서 변경을 보거나 되돌릴 수 있습니다. 사용자 저장소의 `.git`은 건드리지 않습니다. 이 기능에는 git이 필요합니다.
- WARN과 BLOCK 카드에 바뀌는 내용 자체(diff 또는 명령)가 보입니다.
- 40줄이 넘는 기존 파일의 절반 이상을 갈아엎는 수정은 Guard가 확인을 받습니다.

### 대화와 기준

- 앱을 다시 켜도 대화가 그대로 남습니다. 에이전트 답, PDF 질문, 조건, 점검 결과, Guard 카드가 일어난 순서대로 보입니다.
- 대화 중에 "X는 건드리지 마"라고 말하면 그 작업의 기준이 됩니다. 애매하게 말한 기준은 [기준으로 추가] 또는 [무시]를 묻습니다.
- 에이전트는 작업 기준과 확인된 근거를 먼저 알고 시작합니다. 그래서 금지된 일을 시도조차 하지 않는 경우가 많습니다. Guard는 그대로 안전망으로 남습니다.
- 같은 행동에는 이전 판단을 다시 씁니다. 반복해서 읽을 때 기다리는 시간이 줄어듭니다.

## 설치

필요한 것:

- Windows 10/11 x64
- 디스크 여유 2 GB
- 인터넷 연결과 ChatGPT 계정
- (선택) git: 변경 되돌리기에만 필요합니다.

Python, Node.js, Codex CLI는 필요 없습니다.

1. `Get-FileHash .\PabloSetup.exe -Algorithm SHA256` 값이 위 SHA-256과 같은지 봅니다.
2. `PabloSetup.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" → "실행"을 누릅니다.
3. 관리자 권한 없이 현재 사용자에게만 설치됩니다. 설치가 끝나면 Pablo가 열립니다.

| 경로 | 내용 |
|---|---|
| `%LOCALAPPDATA%\Pablo\app-0.7.0` | 앱 (읽기 전용으로 씀) |
| `%APPDATA%\pablo-desktop` | 사용자 데이터 (로그인 정보, 작업 기록, 대화, 체크포인트) |

0.6.0에서 올리면 작업, 대화 thread, 로그인이 그대로 이어집니다.

## 처음 쓰기

3. 📎 PDF와 📁 작업 폴더를 고릅니다.

## 빌드 재현

저장소 `README.md`의 Packaging (M6) 절을 따릅니다.

```bash
npm --prefix desktop run backend
npm --prefix desktop run make
```

결과: `desktop/out/make/squirrel.windows/x64/PabloSetup.exe`
배포 구성과 라이선스 표는 0.6.0과 같습니다(`../0.6.0/README.md`).
