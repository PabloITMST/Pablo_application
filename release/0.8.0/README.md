# Pablo 0.8.0

Pablo는 ChatGPT 계정으로 Codex 에이전트를 쓰는 Windows 데스크톱 앱입니다.
작업 기준을 지키는지 Guard가 확인합니다.
논문을 재현하는 작업이면 논문의 조건을 원문 쪽에 고정하고, 코드가 그 조건에서 벗어났는지 점검합니다.
0.8.0은 점검 결과를 Pablo가 직접 확인하고, 자료를 여러 편으로 넓히고, 조건을 사람이 고칠 수 있게 했습니다.

## 0.7.0 이후 바뀐 것

### 재현 점검을 Pablo가 확인합니다

- 🔎 재현 점검의 판정마다 붙는 파일:줄을 Pablo가 직접 읽어 확인합니다. 모델이 댄 줄에 그 값이 있으면 확인, 몇 줄 옆에 있으면 "위치 보정: N줄", 없으면 그렇다고 표시합니다.
- 점검표나 변경 카드의 파일:줄을 누르면 오른쪽 코드 패널이 그 줄을 칠해 보여 줍니다. 읽기 전용입니다.
- 점검 뒤에 파일이 바뀌면 점검 카드가 오래됐다고 알립니다. 카드는 확인했던 자리를 다시 대조합니다.
- 조건에 종류가 붙습니다(설정, 결과, 서술 사실, 실험 범위). 서술 사실과 실험 범위는 점검하지 않아 점검표가 조용해졌습니다.
- 표의 한 행을 인용한 결과 조건에 열 이름이 없으면 "? 열 짝 확인 필요"로 보이고, 확인 전에는 판정하지 않습니다.
- 방법이 값을 어떻게 쓰는지(쓰임새 조건)도 뽑고 점검합니다. 어느 조건에도 들지 않는 어긋남은 점검표 끝에 따로 적습니다.

### 조건을 사람이 고칩니다

- PDF에서 문장을 골라 재현 조건으로 더할 수 있습니다(종류를 먼저 고릅니다). 비슷한 조건이 이미 있으면 먼저 알려 줍니다.
- 조건을 뺄 때는 이유를 적습니다. 뺀 조건은 남아 있고 되살릴 수 있습니다.
- ◇ 의도한 차이: 논문 조건과 일부러 다르게 할 때 이유를 남기고 진행합니다. 기본 범위는 "별도 실행에서만"입니다.
- 조건을 다시 뽑아도 사용자가 더하거나 뺀 것, 의도한 차이는 그대로 남고, 무엇이 바뀌었는지 보여 줍니다.
- 조건 뽑기가 참고문헌 뒤의 부록을 한 번 더 읽습니다. 표에만 있는 설정(배치 크기, 입력 크기)과 문제 정의를 더 찾습니다. 대신 시간이 늘었습니다(LinearRAG 43초 → 약 3–4분, `KNOWN_LIMITATIONS.md` 15번).

### 자료가 넓어졌습니다

- 한 작업에 논문 여러 편을 붙입니다. 재현하는 논문(주 논문)의 조건만 Guard와 점검에 쓰입니다.
- arXiv 번호·링크, 논문 검색, OpenReview, DOI로 논문을 가져옵니다. 웹 페이지도 자료가 됩니다. 어디에 무엇을 보냈는지 밝힙니다.
- 여러 자료에 한 번에 묻습니다. 답의 [n]은 그 자료의 쪽을 엽니다.
- 📊 비교표: 논문마다 데이터셋, 지표, 값을 나란히 놓습니다. 칸마다 원문 쪽이 붙고, 두 논문이 함께 쓰는 데이터셋은 따로 묶습니다.
- 논문 PDF의 링크에서 공식 코드 저장소를 찾아 옆에 보여 주고, 에이전트에게도 알려 줍니다.

### 기준과 작업

- 사용자가 쓴 기준이 조용히 버려지지 않습니다. 기준으로 읽지 못한 줄은 "❔ 기준으로 읽지 못했습니다"로 보입니다.
- 기준 패널에서 기준을 고칠 수 있습니다. 지운 기준도 남아 있고 되살릴 수 있습니다.
- 작업 목록에서 이름을 바꾸고, 검색하고, 보관합니다.
- 📄 보고서: 재현 작업을 Markdown 보고서로 저장합니다. 조건마다 논문 쪽, 의도한 차이와 뺀 것의 이유, 마지막 점검과 그 뒤의 변경이 들어갑니다.

### Windows

- 에이전트가 한글 주석이나 λ 같은 문자가 든 파일을 읽어도 깨지지 않습니다(UTF-8 콘솔).
- PowerShell 7이 없는 PC에서는 로그인 뒤 한 번 설치를 안내하고, 에이전트에게 UTF-8로 읽으라고 알립니다.

## 설치

필요한 것:

- Windows 10/11 x64
- 디스크 여유 2 GB
- 인터넷 연결과 ChatGPT 계정
- (선택) git: 변경 되돌리기에만 필요합니다.
- (권장) PowerShell 7: 한글이 든 코드를 정확히 읽는 데 필요합니다(`winget install Microsoft.PowerShell`).

Python, Node.js, Codex CLI는 필요 없습니다.

1. `Get-FileHash .\PabloSetup.exe -Algorithm SHA256` 값이 위 SHA-256과 같은지 봅니다.
2. `PabloSetup.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" → "실행"을 누릅니다.
3. 관리자 권한 없이 현재 사용자에게만 설치됩니다. 설치가 끝나면 Pablo가 열립니다.

| 경로 | 내용 |
|---|---|
| `%LOCALAPPDATA%\Pablo\app-0.8.0` | 앱 (읽기 전용으로 씀) |
| `%APPDATA%\pablo-desktop` | 사용자 데이터 (로그인 정보, 작업 기록, 대화, 체크포인트) |

0.7.0에서 올리면 작업, 대화 thread, 로그인이 그대로 이어집니다.

## 처음 쓰기

1. "ChatGPT로 계속하기"로 로그인합니다.
2. **+ 새 작업**에서 목표와 기준을 적습니다. 논문 재현이면 "논문 재현 작업"을 고릅니다.
3. 📎 PDF(또는 arXiv·DOI)와 📁 작업 폴더를 고릅니다.
4. 📋 재현 조건 뽑기 → 요청 → 🔎 재현 점검 → 파일:줄을 눌러 코드 확인.

시연 순서는 `DEMO_SCENARIO.md`에, 알려진 제한은 `KNOWN_LIMITATIONS.md`에 있습니다.
