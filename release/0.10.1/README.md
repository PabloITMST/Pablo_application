# Pablo 0.10.1

Pablo는 ChatGPT 계정으로 Codex 에이전트를 쓰는 Windows 데스크톱 앱입니다.
작업 기준을 지키는지 Guard가 확인합니다.
논문을 재현하는 작업이면 논문의 조건을 원문 쪽에 고정하고, 코드가 그 조건에서 벗어났는지 점검합니다.
0.10.1은 10/27–28 캡스톤 시연을 녹화하며 찾은 문제를 고친 판입니다. 기능과 화면 구성은 0.10.0과 같습니다.

## 0.10.0 이후 바뀐 것

### 대화

- **긴 메시지가 줄바꿈됩니다.** 입력창이 8줄까지 늘어나고, 그보다 길면 스크롤됩니다. Enter는 보내기, Shift+Enter는 줄바꿈입니다.
- **"작업 중"이 대화 맨 아래에 보입니다.** 입력창 대신 대화의 마지막 메시지로, 생각하는 캐릭터와 함께 걸린 시간(m:ss)을 보입니다.
  그 아래에 지금 하는 일을 세 줄까지 보입니다. 에이전트가 마지막으로 쓴 문단, 진행 카드의 줄, 또는 "확인 카드에서 진행할지 기다립니다"입니다.
- **대화가 맨 아래를 따라갑니다.** 답이 오거나 카드가 늘어나도 맨 아래에 머뭅니다. 사용자가 휠·키·스크롤바로 위로 올리면 그 자리에 멈추고, 다시 맨 아래로 내리거나 메시지를 보내면 따라가기를 다시 시작합니다.

### 오른쪽 열

- **폭을 바꿀 수 있습니다.** 열의 왼쪽 가장자리를 끌면 폭이 바뀌고, 두 번 누르면 넓게 보기와 원래대로를 오갑니다. 패널 머리의 **↔ 넓게 보기**도 같습니다. 정한 폭은 다음 실행에도 남습니다.
- **PDF 뷰어를 다시 만들었습니다.**
  - 모든 쪽이 한 번에 스크롤됩니다. 보이는 쪽 근처만 그립니다.
  - 기본은 열 폭에 맞춤입니다. 열 폭이 바뀌면 다시 맞춥니다.
  - **−** · 배율 · **+** · **폭 맞춤** 버튼과 Ctrl+휠로 확대·축소합니다. 확대하면 가로로도 스크롤됩니다.
  - 스크롤하면 지금 보는 쪽이 "N / M"으로 바뀌고, "이 쪽을 인용한 대화"도 그 쪽을 따라갑니다. **이전 쪽** · **다음 쪽**은 그 쪽으로 스크롤합니다.
  - 근거 강조는 어느 배율에서도 그 문장 위에 그려집니다. 문장을 골라 재현 조건으로 더하기는 어느 쪽에서나 됩니다.
- **버튼 모양을 맞췄습니다.** 대화와 오른쪽 열의 카드 안 동작은 모두 테두리 있는 버튼입니다. 카드 아래 동작 줄은 32px, 줄 안의 작은 동작은 24px입니다.
  코드 패널의 **VS Code** · **폴더**는 같은 모양의 버튼입니다. 글 속 인용 [n]과 파일:줄만 링크로 남았습니다.

### 그 밖

- 사이드바 왼쪽 위와 **설정 · 정보**의 로고가 "P" 네모 대신 Pablo 캐릭터입니다.

### 고친 것

- **조건이 두 곳에 걸린 점검 행**(예: `config.yaml:5; run.py:3`)의 코드를 열면, 점검 직후인데도 "지금은 없습니다" 경고가 뜨던 것. 이제 점검이 본 모든 자리에서 찾습니다.
  보고서 내보내기의 "점검 뒤 바뀐 곳"도 그런 행을 두 번 세지 않고 첫 자리로 셉니다.
- **보고서 내보내기 대화상자**에 "null"이 글자로 찍히던 것.

## 설치

0.9.0과 같습니다(`../0.9.0/README.md`의 "설치" 절). 0.10.0에서 올리면 작업, 대화, 로그인이 그대로 이어집니다.

1. `Get-FileHash .\PabloSetup.exe -Algorithm SHA256` 값이 위 SHA-256과 같은지 봅니다.
2. `PabloSetup.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" → "실행"을 누릅니다.

| 경로 | 내용 |
|---|---|
| `%LOCALAPPDATA%\Pablo\app-0.10.1` | 앱 (읽기 전용으로 씀) |
| `%APPDATA%\pablo-desktop` | 사용자 데이터 (로그인 정보, 작업 기록, 대화, 체크포인트) |

## 빌드 재현

저장소 `README.md`의 "패키징" 절을 따릅니다.

```bash
npm --prefix desktop run backend
npm --prefix desktop run make
```

결과: `desktop/out/make/squirrel.windows/x64/PabloSetup.exe`
번들한 서드파티 구성 요소와 라이선스는 `THIRD_PARTY_NOTICES.txt`에 있습니다. 0.10.0과 같습니다.
