# Pablo 0.10.1 — 알려진 제한사항

이전 버전의 제한은 그대로입니다.
- 0.6.0의 1, 3, 4, 6–10번(`../0.6.0/KNOWN_LIMITATIONS.md`): 서명 없는 설치 파일, Electron fuse 미설정, PDF 첫 열기 지연, 용량, 자동 업데이트 없음, Codex crate 라이선스 목록, Windows x64 전용, 깨끗한 PC 검증 미완료.
- 0.7.0의 2, 12–14번(`../0.7.0/KNOWN_LIMITATIONS.md`): 처음 보는 읽기 명령의 Guard 지연, 되돌리기에 git 필요, 인터넷은 작업마다 직접 켬, 긴 실험은 앱 밖에서.
- 0.8.0의 11, 15–18번(`../0.8.0/KNOWN_LIMITATIONS.md`): 재현 조건과 점검은 모델의 판단(일부를 Pablo가 확인), 부록을 읽어 느려진 조건 뽑기, 표 숫자의 열 짝, PowerShell 7이 없는 PC, 바깥 서비스를 쓰는 논문 가져오기.
- 0.9.0의 19–22번(`../0.9.0/KNOWN_LIMITATIONS.md`): 한국어·밝은 테마뿐, 기록에서 계산하는 단계, 모델이 쓰는 단계 요약, 작게 남은 화면 문제.
- 0.9.1의 24–26번(`../0.9.1/KNOWN_LIMITATIONS.md`): 기준을 대놓고 어기는 요청은 에이전트가 먼저 거절함, 애매한 말을 묻는 동안 에이전트가 움직일 수 있음, 점검 행 수와 위치 수의 차이.
- 0.10.0의 27–31번(`../0.10.0/KNOWN_LIMITATIONS.md`): 실제 계정으로 확인하지 않은 것, 기기 코드 연결 없음, 어림값 진행률, 로그 파일 없음, 규칙으로 고르는 제안 태그.

27번은 그대로입니다. 0.10.1에서는 그 대신 실제 계정으로 시연 장면 A–D를 설치본과 같은 빌드로 끝까지 돌렸습니다(`README.md`의 "검증" 절).

## 32. PDF 뷰어

- 처음 열 때 모든 쪽의 크기를 먼저 읽습니다. LinearRAG(19쪽)는 첫 열기가 0.3초 안팎이었습니다. 수백 쪽짜리 PDF에서는 재지 않았습니다.
- 확대는 30%–400%입니다. 쪽 번호를 입력해 바로 가는 칸은 없습니다. 스크롤하거나 **이전 쪽** · **다음 쪽**을 씁니다.
- 두 쪽에 걸친 문장은 재현 조건으로 고를 수 없습니다. 한 쪽 안의 문장만 고릅니다.

## 33. 보고서 저장 카드는 그 실행 동안만 보입니다

- 보고서를 저장하면 대화에 "보고서를 저장했습니다" 카드가 붙습니다. 앱을 다시 열면 이 카드는 보이지 않습니다. 0.10.0부터 그랬습니다.
- 보고서 파일과 단계 막대의 **보고서** 단계("저장함")는 남습니다.

## 34. "작업 중"의 설명은 에이전트의 글 그대로입니다

- "작업 중" 아래의 설명은 에이전트가 마지막으로 쓴 문단입니다. Pablo가 요약하지 않습니다.
- 에이전트가 글 없이 명령만 실행하는 동안에는 바로 앞 문단이 그대로 남습니다.

## 35. 설치

- 설치하면 바탕화면과 시작 메뉴에 `Pablo.lnk`를 만듭니다. 바탕화면에 같은 이름의 바로가기가 있으면 덮어씁니다(Squirrel 설치기의 동작). 시연용 바로가기 같은 것은 다른 이름으로 두세요.
- 0.10.1은 0.10.0 설치본이 없는 PC에 새로 설치해 확인했습니다. 0.10.0 → 0.10.1 업그레이드 경로는 확인하지 않았습니다.
