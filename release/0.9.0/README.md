# Pablo 0.9.0

Pablo는 ChatGPT 계정으로 Codex 에이전트를 쓰는 Windows 데스크톱 앱입니다.
작업 기준을 지키는지 Guard가 확인합니다.
논문을 재현하는 작업이면 논문의 조건을 원문 쪽에 고정하고, 코드가 그 조건에서 벗어났는지 점검합니다.
0.9.0은 화면을 새로 짰습니다. 작업은 단계로 진행되고, 대화는 단계별로 나눠 볼 수 있으며, 메시지를 기준이나 결정으로 고정할 수 있습니다.

## 0.8.0 이후 바뀐 것

### 화면을 새로 짰습니다

- 세 칸 구성입니다. 왼쪽은 작업 목록, 가운데는 대화, 오른쪽은 **기준 · 계획 · 왜? · 근거** 탭입니다. 오른쪽 칸을 접으면 얇은 레일로 남습니다.
- 자료, 작업 폴더, 인터넷은 머리줄의 상태 칩으로 옮겼습니다. 자료 칩을 누르면 소스 카드가 열립니다. 카드에서 논문 목록과 주 논문, 공식 코드 링크를 보고, **+ 추가**로 PDF·arXiv·DOI·웹 페이지를 붙입니다.
- 머리줄 아래 **단계 막대**가 작업의 진행을 늘 보여 줍니다. 작업 종류마다 단계가 다릅니다.
  - 논문 재현: 준비 → 조건 확정 → 구현·실행 → 재현 점검 → 보고서
  - 논문 읽기: 준비 → 질문 → 비교표 → 정리
  - 일반: 준비 → 작업 → 검토
- 0.8.0의 도구 막대 버튼(재현 조건 뽑기, 재현 점검, 비교표, 보고서)은 해당 단계 안으로 들어갔습니다. 단계는 순서를 강제하지 않습니다. 필요한 것이 없을 때만 "막힘"과 이유를 보입니다.
- 보낼 곳(에이전트 / 논문 질문)은 입력창 안으로, 모델 선택은 입력창의 글자 버튼으로 옮겼습니다.
- 글꼴(Pretendard, Geist, Geist Mono)을 앱에 넣었습니다. 시스템 글꼴과 상관없이 같은 모양으로 보입니다.

### 대화를 단계로 나눠 봅니다

- 메시지마다 단계 태그가 붙고, 단계가 바뀌는 곳에 구분선이 생깁니다. 단계 막대를 눌러 그 단계의 메시지만 거를 수 있습니다.
- 입력창이 "이 메시지는 ○○로 기록"이라고 미리 알려 줍니다.
- **✎ 태그**로 메시지의 단계를 바꾸거나 **결정으로 고정**합니다. 결정으로 고정한 메시지는 단계별 보기의 결정 목록과 재현 보고서에 들어갑니다.
- 보기는 세 가지입니다. **시간순**(기본), **단계별**(지난 단계는 요약과 결정으로 접힘), **대상별**(파일, 논문 쪽, 대상 없음 순으로 묶음).
- 단계별 보기에서 **✦ 요약 쓰기**를 누르면 모델이 그 단계를 두 문장 안팎으로 요약합니다. 누를 때만 모델을 부릅니다. 사람이 고친 요약이 이기고, 다시 써도 유지됩니다. 요약 뒤에 메시지가 더 쌓이면 "그 뒤 메시지 N개"로 알립니다.

### 작업

- 새 작업을 만들 때 종류를 고릅니다: **논문 재현**, **논문 읽기**, **일반**(기본). 논문 재현은 0.8.0처럼 재현 기준 세 개를 함께 넣습니다.
- **📌 기준으로**: 대화의 메시지를 그 작업의 기준으로 바로 만듭니다. 보류된 기준이면 바로 확정합니다.
- 보고서를 저장하면 작업을 완료로 옮길지 묻습니다. 완료한 작업은 사이드바의 **완료** 묶음으로 접히고, 다시 풀 수 있습니다.
- **설정**(계정 카드에서 엶): 기본 보기, 태그를 얼마나 보일지, 오른쪽 칸 기본값, 인터넷 기본값.
- 오른쪽 칸의 열림과 탭을 작업마다 기억합니다. 새 작업은 기준 탭이 열린 채 시작합니다.

### QA에서 고친 것

실제 계정 QA(2026-10-26)에서 찾은 결함을 고쳤습니다.

- 결정으로 고정한 메시지가 보고서에 들어가지 않던 것.
- 입력창의 "○○로 기록" 안내와 실제로 붙는 태그가 다르던 것.
- 방금 끝난 턴의 메시지에 태그 줄, ✎ 태그, 📌 기준으로가 작업을 다시 열기 전까지 없던 것.
- 같은 실행 안에서 다른 작업에 갔다 오면 오른쪽 칸이 닫히던 것. 앱을 켤 때 다시 여는 작업의 칸도 복원합니다.
- 대상별 보기가 메시지를 첫 대상 하나에만 묶던 것.
- 모델 메뉴, 소스 카드, 설정이 Esc나 바깥 클릭으로 닫히지 않던 것.
- PDF를 추가한 뒤에도 추가 상자가 대화를 가리던 것.
- 좁은 창에서 머리줄의 작업 이름과 상태 칩이 잘리던 것.
- 일반 작업의 재현 점검 버튼이 단계 밖에 떠 있던 것. 이제 검토 단계에 있습니다.
- 단계 막대는 ✓인데 단계별 상자는 "진행"으로 보이던 것.
- 요약의 `코드` 표시가 백틱 그대로 보이던 것.
- 설치본의 `THIRD_PARTY_NOTICES.txt`에서 글꼴 경로가 제어 문자로 깨져 있던 것.

## 0.8.0 문서를 0.9.0에서 따라 할 때

시연 시나리오와 깨끗한 PC 점검표는 0.8.0 것을 그대로 씁니다(`../0.8.0/DEMO_SCENARIO.md`, `../0.8.0/CLEAN_MACHINE_TEST.md`). 기능과 순서는 같고, 버튼 자리만 바뀌었습니다.

| 0.8.0 문서의 표현 | 0.9.0에서 찾는 곳 |
|---|---|
| **+ 새 작업** → **논문 재현 작업** 체크 | **+ 새 작업** → 종류 **논문 재현** |
| 위쪽 **기준** | 오른쪽 칸의 **기준** 탭 |
| 📎 PDF, 📎 PDF 추가 | 머리줄 자료 칩 → 소스 카드 → **+ 추가** |
| 📁 작업 폴더 | 머리줄 폴더 칩 |
| 🌐 인터넷 | 머리줄 인터넷 칩 |
| 📋 재현 조건 뽑기 | 단계 막대 **조건 확정** 안의 **재현 조건 뽑기** |
| 🔎 재현 점검 | 단계 막대 **재현 점검** |
| 📊 비교표 | 논문 읽기 작업은 단계 막대 **비교표**. 다른 작업은 논문이 두 편 이상일 때 단계 막대 오른쪽 끝의 **📊 비교표** |
| 📄 보고서 | 단계 막대 **보고서**(재현) · **정리**(읽기) · **검토**(일반) |
| 💬 보낼 곳 | 입력창 안의 **에이전트 / 논문 질문** |
| 계정 상태, 연결 해제 | 사이드바 아래 계정 카드 |

## 설치

필요한 것:

- Windows 10/11 x64
- 디스크 여유 2 GB
- 인터넷 연결과 ChatGPT 계정
- (선택) git: 변경 되돌리기에만 필요합니다.
- (권장) PowerShell 7: 한글이 든 코드를 정확히 읽는 데 필요합니다(`winget install Microsoft.PowerShell`).

Python, Node.js, Codex CLI는 필요 없습니다.

1. `Get-FileHash .\PabloSetup.exe -Algorithm SHA256` 값이 위 SHA-256과 같은지 봅니다.
2. `PabloSetup.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" → "실행"을 누릅니다.
3. 관리자 권한 없이 현재 사용자에게만 설치됩니다. 설치가 끝나면 Pablo가 열립니다.

| 경로 | 내용 |
|---|---|
| `%LOCALAPPDATA%\Pablo\app-0.9.0` | 앱 (읽기 전용으로 씀) |
| `%APPDATA%\pablo-desktop` | 사용자 데이터 (로그인 정보, 작업 기록, 대화, 체크포인트) |

0.8.0에서 올리면 작업, 대화 thread, 로그인이 그대로 이어집니다. 0.8.0에서 만든 작업은 종류를 자료와 폴더로 정합니다. 논문과 작업 폴더가 둘 다 있으면 논문 재현, 논문만 있으면 논문 읽기, 그 밖은 일반입니다. 기준과 Guard는 0.8.0과 같이 동작합니다.

## 처음 쓰기

1. **ChatGPT로 계속하기**로 로그인합니다.
2. **+ 새 작업**에서 목표와 기준을 적고 종류를 고릅니다. 논문 재현이면 **논문 재현**입니다.
3. 머리줄에서 자료(PDF, arXiv, DOI)와 작업 폴더를 고릅니다.
4. 단계 막대를 따라갑니다: 재현 조건 뽑기 → 에이전트에게 요청 → 재현 점검 → 파일:줄을 눌러 코드 확인 → 보고서.

## 빌드 재현

저장소 `README.md`의 "패키징" 절을 따릅니다.

```bash
npm --prefix desktop run backend
npm --prefix desktop run make
```

번들한 서드파티 구성 요소와 라이선스는 `THIRD_PARTY_NOTICES.txt`에 있습니다. 0.8.0에 글꼴 세 개(SIL OFL 1.1)가 더해졌습니다.
